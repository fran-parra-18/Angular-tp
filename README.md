# 🅰️ Angular Web Application

A frontend application developed with Angular as part of my Software Development studies.

The project focuses on learning Angular's component architecture, TypeScript and the organization of a structured single-page application.

## 🎯 Project Goals

The main objective of this project was to practice fundamental Angular concepts and understand how larger frontend applications can be divided into independent and reusable components.

## 🛠️ Tech Stack

* Angular
* TypeScript
* HTML5
* CSS
* Node.js
* npm

## 🧩 Angular Architecture

The application follows Angular's component-based development model.

```text
Angular Application
│
├── Components
├── Templates
├── TypeScript Logic
├── Styles
└── Application Configuration
```

This structure separates presentation, application logic and configuration into maintainable parts.

## 🚀 Running Locally

### Requirements

* Node.js
* npm
* Angular CLI

Clone the repository:

```bash
git clone https://github.com/fran-parra-18/Angular-tp.git
cd Angular-tp
```

Install dependencies:

```bash
npm install
```

Start the Angular development server:

```bash
ng serve
```

Then open:

```text
http://localhost:4200
```

The application automatically reloads when source files are modified.

## 🏗️ Build

Create a production build with:

```bash
ng build
```

Angular will compile the project and generate the production files in the configured output directory.
